# k-sasuke — THIRD STAGE 3D v4.5.0

第43回SASUKEの3rd STAGEを参考にした非公式3Dゲーム。横画面専用、全6エリアが一続きのセットです。TBS・番組公式とは関係ありません。

## 横画面・3ボタン

画面内に大きな操作ボタンを置いています。初期カメラは近接追従。縦画面では横向き案内を表示し、時間と筋持久力を停止します。

| ボタン | キーボード | 操作 |
|---|---|---|
| 振る | A / D / 左右キーの長押し | 振りの位相に合わせて体を前後に振る。円柱では「横移動」に切り替わり、抱きついたまま回り込む |
| 保持 | Cの長押し | 押している間だけ有効。円柱は長押しで登り、掴む瞬間にも必要。掴んだ後は離してOK。クリフは手送り、パイプは前進。BURSTでは回転の持ち替え時に使用し、長押し中は消費が増える |
| ジャンプ | Space | 現在の勢いで離す。円柱では「蹴る」に切り替わり、脚を伸ばして離脱。BURSTでは「移動」の長押し、休憩台では「挑戦する」に変わる |

保持の切り替え固定はありません。指を離す・タッチキャンセル・一時停止・画面の向き変更で解除。左右方向・背面ジャンプの反転は操作層が選びます。ジャンプのタイミングはプレイヤーが決め、ボタン連打だけでは進めません。

◈で追従→近接追従→側面→全景→選手視点。画面ドラッグで見回し。Ⅱ / P / Escapeで一時停止。メニューからエリアを選び、その地点から最後まで練習できます。WebGL 2対応Safari / Chromeが必要です。

## セット・選手・負荷

- エリア境界でセットや選手位置をリセットしません。クリア画面・次へ進むダイアログはありません。
- フライングバーの支持は固定。最後の皿へバーを残し、円柱へ手ぶらで跳びます。
- サイドワインダーは4円柱。1・3本目の常時回転、2本目の荷重落下、吊り部の上端固定、よじ登り・蹴り出し・リーチ・抱え込みを表現。円柱へ広めの飛行経路判定を使い、着手高さを登り量へ反映します。
- サイドワインダーとスイングエッジの間は着地できる休憩台。「挑戦する」で次へ進みます。
- スイングエッジは進行方向を向いたX–Y–Xフレーム。Xは左右2か所、Yは中央1か所の突起を逆手で保持。最後のアクリル板もフレームと同じ向き。
- クリフは対向配置・横移動・上下／奥行き可動。BURSTは黄→赤→赤→黄の4シリンダー。黄色は前半・後半それぞれ120°間隔の3枚の放射状突起で、後半を60°ずらします。中央で斜め上の後半突起を掴み、シリンダーを60°引き下ろします。赤色は下側の保持突起と上側の飾り。3本目は奥へ30cm、4本目はさらに奥へ60cmずらし、移動中は片手ずつ滑らかに手を送ります。色合いは既存の黄／赤・黒・銀を維持します。
- パイプは5.3mレール。速度の減衰を0.8/秒から0.025/秒へ低減。重心と体振りの反作用が速度へ作用し、惰性や後滑りが続きます。保持による前進で立て直せます。
- 腕と脚は関節付きの手続き型モデル。円柱登攀時の揺れを抑え、BURST回転中の膝の引き付け、交互の手送り、着手の衝撃吸収を表現。視点・着地・水面接触は共通の身体モデルを使います。
- 筋持久力は小さい時間消費＋保持負荷＋跳躍・着手・回転の負荷。0で落下。各エリア初回突破で20回復、クリフ突破後だけ30回復（上限100）。
- 横移動中はクリフ約1.42%/秒、BURST約0.84%/秒（本番、振りなし）。クリフの跳躍は3.5%、円柱の蹴り出しは1.8%、その他の離脱は1.2%、着手は速度依存。1本目の回転区間は角度進行ごとに3%、計12%消費。4本目は3.3%ずつ計13.2%。BURSTで保持を押している間はさらに3.2%/秒、4本目の持ち替え・回転中の時間消費全体は1本目の1.1倍です。
- 休憩台は「挑戦する」を押すまで次へ移行しません。休憩中も小さい時間消費は続きます。

## 開発・公開

Node.js 20以上。

```sh
npm ci
npm test
npm run build
```

`dist`を配信します。Three.jsはビルド時に同梱し、実行時CDNは使いません。VercelはFramework Other、Build Command `node build.mjs`、Output Directory `dist`。環境変数は不要です。

- `src/burst.mjs`: 前後の放射状突起・60°回転・手の持ち替えの共通定義。
- `src/course.mjs`: 一続きの装置座標。
- `src/controls.mjs`: 3ボタンをエリア別の動作へ変換。ジャンプのタイミングは自動化しません。
- `src/collision.mjs`: つかみ判定と独立した物理形状、連続衝突、運動量・回転の応答。
- `src/engine.mjs`: 運動・保持・荷重・手送り・筋持久力。
- `src/motion.mjs`: 関節・姿勢・足の接触位置。
- `src/render.js`: 3Dセットと5種類のカメラ。
- `src/app.js` / `src/template.html`: 横画面UI・ポインター／キー入力。
- `docs/research-43.md`: 公式資料、提供動画の照合記録と制限。

## BURSTの進め方

「移動」で黄色の中央まで進み、「振る」を軽く押して60°斜め上の突起へ手を伸ばし、「保持」で掴みます。掴んでからシリンダーを60°引き下ろし、回転が止まったら保持を離して移動を続けます。中央以外では持ち替え・回転を始められず、保持なしで持ち替えたり引き下ろしたりすると落下します。赤色の固定シリンダーは移動だけで通過できます。

1本目と4本目は同じ突起構造。前半は0°・120°・240°、後半は60°・180°・300°の長手方向の突起で、両半分をシリンダーと一緒に60°回します。4本目の回転負荷は1本目より10%増。2→3本目は奥へ30cm、3→4本目はさらに60cm移動します。突起間は移動を長押しして滑らかに渡り、離すと途中で止められます。

## 衝突・クリフの負荷・足場

- つかみ成功の半径・幅・高さは維持。成功判定を先に処理します。失敗時は頭・胴・手・肘・膝・足の球群と、装置の別形状で接触を判定。届いていない軌道には衝突を発生させません。
- フレーム・アクリル・壁・回転板・バー・レール・円柱を連続走査し、薄い板や高速移動のすり抜けを抑制。可動装置の表面速度も衝突へ反映します。
- 反発・接線摩擦・質量・回転慣性による近似応答。接線方向の速度や衝突前の上向き速度を残し、接触点の衝撃から体の回転を計算。円柱は揺れ、エッジ／黄色板は軸周りに揺れ、固定物は固定のままです。選手視点も落下中の回転を追います。
- クリフの2回目の飛び移り（中央→最後）は、通常の着手負荷に追加負荷。追加量は `min(14, 2 + max(0,距離cm−180)×0.035 + max(0,最高点からの落差cm−30)×0.045)`。飛距離・落差が大きいほど消費が増えます。
- サイドワインダー後・エッジ後の足場は前後左右の着地許容を40cm拡大し、見た目の足場も合わせて拡大。BURST後と最終足場は同じです。
- パイプで保持ボタンを押している間の時間消費は、同じ入力の従来値の1.5倍。通常20回復・クリフ後30回復は維持します。

衝突は球群・直方体・円柱と軸拘束を使う簡易剛体モデルです。全身の関節を独立に解くラグドール、装置の変形、番組実機の質量・摩擦の実測再現ではありません。実ブラウザでの見え方と実機の手触りは未検証です。

着地は反発・摩擦・転倒の物理応答から除外。足が足場の上面へ届いたら直立位置へ固定し、速度・回転をゼロにします。休憩台・最終足場ともに滑らず、保持ボタンも不要です。既にリタイアした選手の着地で攻略を再開することはありません。

スイングエッジの通常モーションは衝突物理導入前の版へ復元。飛び移り中の追加の腕の構えを解除し、通常の保持・振り・飛行には装置の衝突反動を加えません。衝突失敗後の落下時だけ、体の回転とエッジの反動を適用します。

## v4.3 動画に合わせた操作

サイドワインダーでは「横移動」を長押しして円柱の周りを回り込み、位置ゲージ55%以上・高さ35cm以上で「蹴る」を押すと、0.22秒の脚の伸展後に離れます。保持では上へ登り、横移動では高さを変えずに回り込みます。1・3本目は入力・接触の有無にかかわらず常時軸回転、2本目は荷重で60cm落下、4本目は固定です。次の円柱を掴む瞬間は保持必須で、その後は保持を離しても支持を続けます。保持を再び押すと登攀できます。

BURSTの色合いは既存のまま、形状・回転角はv4.5のユーザー指定に更新。以前の対向板・180度回転・最後の固定端は使いません。120°／60°の角度と奥行き30／60cmは指定に合わせています。シリンダーの半径・全長・操作にかかる時間はゲーム用の推定です。

## スイングエッジの落下参照（v4.3.1）

2026-10-19提供のリタイア集（約45.87秒）の落下部分だけを参照。エッジ失敗時に限り、手が外れた瞬間の角度・進行方向・腕脚の位置を保存し、腕の解放と膝の曲がりを時間差で補間。ぶら下がりからの失敗は体振りの接線方向の速度を引き継ぎ、空中では既存の速度を保ちます。胴体やアクリルへの衝突では背中側への入水を想定した脚の引き付けに変わります。強い回転の上限と減衰をエッジ落下だけ調整しました。

成功時の振り・飛行姿勢・つかみ範囲・装置の動きは維持。他エリアの落下、地面への固定着地、サイドワインダー／BURSTの操作は変更しません。映像から採取したモーションではなく、確認できた落ち方を参考にした手続き型の近似です。

## v4.4 クリフの落下・サイドワインダー補正

クリフは新しい落下参考動画を基に、手が外れた時の背面ジャンプの向き・腕の高さを維持し、腕を時間差で解放、左右で異なる膝の曲がりへ移行します。成功時の操作・手送り・ジャンプ・判定幅・2回目の飛距離／落差の負荷は変更しません。

サイドワインダーは保持長押しで登り、横移動長押しで円柱の周りを移動、蹴るで離脱。両方の長押しも可能です。1・3本目の回転は常時0.72rad/秒（ゲーム用の暫定値）で、回り込みとは独立。2本目の60cm落下、4本目の固定を維持。接触失敗は反発係数0と弱い接線抵抗で滑り、円柱近くからの落下開始は短い速度抵抗と抱え姿勢の解放を挟みます。滑り落ちる接触処理はサイドワインダーだけに適用します。クリフは通常の衝突処理を使い、落下姿勢のみ参考動画に合わせます。エッジの落下、BURST、地面への固定着地のルールは維持します。

## v4.5 BURSTの構造・持ち替え・連続移動

黄色は前後の各半分に3枚ずつの突起。中央のずれた突起へ手を伸ばす段階ではシリンダーを回さず、保持して掴んだ後に60°引き下ろします。体の傾き・引き付けも回転の停止に合わせて弱まります。

突起間には連続した手送り状態を追加。移動距離に応じた時間で体と手が次の突起へ移り、到着時の座標も一致させています。30cm／60cmの奥行き移動、途中の移動ボタン解除、最初のクリフからBURSTへの接続も同じ方式。全体の時間・筋持久力・シーンをリセットしません。

突起数・角度・前後のずれ、中央限定の操作、掴んでからの回転、最終回転の衝撃／時間消費の1.1倍、区間移動の1フレームごとの変位、保持縁と3D支持点の一致、全エリア攻略を検証しています。

## v4.6 表示領域とサイドワインダーの同伴回転

画面回転・Safariの表示領域変化・全画面切替に追従し、毎フレームのキャンバス実寸から投影比率を確認。実寸または画素密度が変わった場合だけ描画バッファを更新します。

サイドワインダーの1・3本目は選手の支持位置と向きも円柱と同じ角速度で回転します。着手時の回転角を基準にし、横移動操作を重ねられます。蹴って離れた後は円柱の回転から切り離します。

## v4.6.1 操作ボタンのタッチ安定化

押下時にボタン自体を移動させず、ラベルは内容が変わった時だけ更新します。ラベルの子要素はタッチを受けず、ボタン本体で一貫して受けます。ボタン外で指を離す／キャンセルした場合も、その指の入力だけを解除します。

## v4.7 サイドワインダーの自由な蹴り出し

横移動量・登った高さによる蹴り出し制限を撤廃。横移動は任意で、終端なしに回り込めます。位置ゲージも到達目標ではなく周回角度へ変更。膝を溜めてから脚を伸ばす0.32秒の蹴り出しと、空中で腕を伸ばす連続姿勢を追加し、飛行速度を強めました。次の円柱に掴まる瞬間の保持は必要。低い位置では飛び出せても届かないことがあり、保持で登って調整できます。

## v4.7.1 縦横比の変化に追従するタッチ判定

タッチ開始時に各ボタンの現在の表示矩形を取得し、CSSピクセルのタッチ座標で独立に判定します。ブラウザが古い配置の要素へ送ったタッチも、画面全体で先に受けて正しい操作へ振り分けます。少しだけ余裕を持たせ、近接時は最も近いボタンを選びます。横画面での表示サイズ変更では保持を継続し、指を離す・キャンセル・縦画面への回転では解除します。

## v4.8 サイドワインダーの背面蹴りと±20°

次のポールへの自動照準を撤廃し、選手の背面へ蹴り出します。ポール中心同士を結ぶ進行方向の直線に対して、離脱時の背面方向が左右20°以内の場合だけ次のポールの掴み判定が有効。範囲外でも蹴れますが、軌道補正せず外れた方向へ飛びます。±20°は必要条件で、届く高さ・距離と着手時の保持も必要です。

画面の角度表示は、蹴り出しまでの円柱の回転を考慮した予測値。横移動の終端なし・円柱との同伴回転・低い位置でも蹴れる仕様は維持。最後のポールから休憩台へも背面へ飛び、足場の着地判定を使います。
