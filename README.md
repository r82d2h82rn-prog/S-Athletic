# S-Athletic

N-Athleticの全4ステージ・ガチSASUKEモードを引き継いだ描画強化版。

## 描画の変更

- 1stを独自WebGL描画からThree.js r180へ移行。コース・当たり判定・操作は継承。
- 全ステージに物理ベースの反射環境、柔らかい影、ACESの色調整を適用。
- 水面はクリアコート付きの素材と時間変化する微細な波で描画。
- 金属・床に微細な凹凸を追加。選手の曲面と一部背景の形状を改善。
- 画面右下の「画質」から軽量・高画質・最高画質を選択。選択は保存され、ページ再読み込み後に適用。
- 3rdの元ソースは保持し、ビルド時に描画のみを加工。物理・操作・コースの出力は元と同一。
- 実行時の外部CDN・画像ダウンロードは不要。

最高画質は解像度倍率2.5、2048pxの影。高画質は倍率1.75、1024pxの影。軽量は倍率1.25、影なし。実際の解像度は端末のdevicePixelRatioを上限とします。

これはリアルな描画を目指した手続き生成モデルの改修です。人物・観客は簡略モデルのため、実写と区別できない品質には達していません。スマホ実機のフレームレートと最終的な映像品質は公開後に確認が必要です。

1つのアプリから1st・2nd・3rd・FINALと「ガチSASUKE」を選べる3Dアスレチックゲーム。
1stは昼の全12エリア、2ndは第43回＋歴代3エリアの全10エリア、3rdは既存k-sasukeの全6エリア、FINALは夜の3区間タワー。

## 1stの物理と描画

参考: ユーザー所有の `r82d2h82rn-prog/k-sasuke`。重力、速度を引き継ぐ離手、減衰のある振り子、下降時の床面交差による着地、保持時の疲労と着地衝撃の設計を参考に、新しい走行コース用に実装。単位はメートル・秒、固定刻み1/120秒。
独立したWebGLレンダラーで3D描画し、ゲームロジックはDOMから分離。汎用の剛体エンジンではなく、アスレチック向けの選手運動モデルです。大型設備と観客は背景で、競技用の当たり判定は足場と保持ポイントにあります。

## v3 コース調整

- ムービングアイランド: 横移動振幅0.95mから1.33m（40%増）。往復の端から端までは1.90mから2.66m。
- ダブルオービット: 半径2.3mから2.0mへ縮小。図形の中心を描画時に上へずらしていた不具合を修正し、足元が実際の上面と一致する。内部・側面の通り抜けを防ぎ、両方の上面に着地する必要がある。最高頂点の高さ4.05mまで約25度の助走坂を登ってから跳ぶ。
- スプリングネット: 最初のつかまり判定は従来のまま（X=108.6、手の高さ6.0〜8.2、横方向も変更なし）。描画する網だけを進行方向に平行な向きへ変更。上端を越えた後は、前進でゴール足場の始端X=114.15まで連続して下る。飛びつき→登り→下り→足場への乗り移りをひとつの操作で行える。

## v4 移動と操作の修正

- 全11か所の境界に連絡足場を配置。休憩足場から次エリアの入口まで床をつなぎ、継ぎ目の着地許容幅を修正。側方ガードを見た目と当たり判定に設け、連絡足場上では横に移動しても水へ落ちない。アスレチック本体の池やジャンプ区間の判定は従来どおり。
- スプリングネットはゴールの地面（連絡足場を含む）への着地でクリア。上端のつかまり・ネット登り切りフラグを次エリア移行時の失格条件から除去。網から早めに飛び降りても、ゴール足場に着地すればそのまま進める。
- 通常モードの制限時間・HUD・タイトルを120秒に統一。練習モードは引き続き時間無制限。
- DASHボタンを削除。前進を一度タッチして離し、280ms以内にもう一度押したままにするとダッシュ。指を離すと歩きへ戻る。長押しだけ・遅い2度押し・同時に2本の指で押す操作ではダッシュにならない。ポーズ、タブ非表示、操作キャンセル、リトライで入力履歴をリセットする。PCのW/↑でも同じ操作を利用でき、Shiftも使える。

## v5 スカイリレーの前方化と滑走延長

- 踏切台は据え置き、1本目の待機バーをX=176.0から177.6へ、2本目を182.25から188.05へ移動。踏切台から1本目までは2.3mから3.9mになり、前方への跳躍が必要。入口の跳躍力とバーの高さも前方跳躍に合わせて調整した。
- 1本目のレーンは4.2mから8.4m、2本目は3.1mから6.2mに延長。直線の斜面を、下降・低い区間・緩い上向きの出口につながる連続したカーブに変更。描画・つかまる位置・速度・離手方向は同じ曲線関数を使用。
- つかんだ速度をそろえた比較で、それぞれの全滑走時間が従来の2倍になるよう運動を校正する。進入速度6.7m/sでは1本目0.50秒→1.00秒、2本目約0.392秒→約0.783秒。進入速度4.0/6.7/8.0m/sで検証。飛びつき・飛び移りの入力タイミングを含めたエリア全体の所要時間は操作により変わる。
- レーン延長に合わせ、着地足場・スパイダー・そり立つ壁を8.9m先へ移動。連絡足場・レーン支持構造・水面・全景カメラ・ゴール位置も対応させた。通常モードは120秒のまま。

曲線形状・体勢の参考: 選手本人の解説 https://note.com/go_to_note/n/n1a2f31720399 、TBS公式写真 https://x.com/sasuke_tbs/status/1826208797439754535 。実物の寸法そのものではなく、ゲームの跳躍距離と操作に合わせた形状として実装。

## v6 そり立つ壁の再挑戦・エリアの移設・スクリューハンマー

- そり立つ壁の下全体に幅6mの着地・助走床と側方ガードを追加。壁で失敗しても床に着地し、バックして助走を取り直せる。ゲーム、時計、コースの進行状況はリセットしない。120秒制限と頂上でのHOLD必須条件は維持する。
- スパイダーウォールとその保持ポイント、半透明壁を廃止。従来の重量ゲート2枚をその位置へ移設し、名前をユーザー指定のインパクトウォールに統一。クリア判定と床・レール・機材も移設。
- 元の重量ゲート区間（AREA 08）はスクリューハンマー。入口で中央の「挑戦」ボタン、またはEnterで起動。停止中は回転しない。起動は一度だけで、6秒で一周すると永久に停止し、2周目のつかまり機会はない。乗り遅れると失敗。
- 約30度のレーンを走ってジャンプし、その瞬間にHOLDを押して回転中の横T字バーをつかむ。一度つかめばHOLDを離しても継続保持。回転に運ばれた先でJUMPして離手し、対岸に着地するとクリア。棒の位置・姿勢・つかまり点・離手速度を一つの回転モデルで共有。
- 見た目は横T字の回転機構、グレーの厚いパッド、赤い端部、金属バンド、駆動部、警戒ストライプの台座、起動スイッチを手続き生成。写真・動画の転載や外部テクスチャの読み込みは行わない。

参考: TBS公式の新エリア紹介 https://www.youtube.com/watch?v=JWwr3VOkxGU 、解説 https://road-to-sasuke.com/screwdriver/ 。公式の回転秒数は確認できていないため、6秒/周はゲーム上の推定設定であり公式規格とはしない。装置のサイズと配置は本コースの跳躍に合わせたもの。

## v8 2nd・FINAL・ガチSASUKE

2ndは第43回の通常8エリアに、アンステーブルブリッジ・バランスタンク・メタルスピンを追加した1つのコースです。ワールドカップ専用コースは含みません。順序と出典、確認できた寸法・未測定の校正値、素材と動きの実装は [調査メモ](docs/sasuke-research-2026.md) を参照。通常8エリアの95秒と区別し、拡張コースは135秒です。FINALは45秒。

上り・下りラダーは同じバーで接続。ラダーの段飛び、バーの水平判定、板の支点数に応じた回転、円筒の転がり、円盤の角運動量と離手、逆流泳ぎ、ベルトの地面速度、壁の質量と重力を個別に計算します。選手の関節・手足を各状態から描画します。全てゲーム向けの運動モデルであり、実選手のモーションキャプチャーや本家の全物理係数を取得したものではありません。

新規の夜ステージは矢印/WASD、HOLD=E/C、JUMP=Space。ラダー・綱はJUMPを短くタップする操作。クライミングの左右の持ち替え、ラダー下りの方向、一度つかんだ後の保持は自動。逆走ベルトは前進長押しで走ります。前進矢印2度押し長押しでダッシュ。タイトル・エリア別練習・操作ガイド・一時停止・追従/側面/全景カメラ・独立した端末記録に対応。夜の照明、観客、トラス、水面、手続き生成の金属・パッド・木目・縄・壁・ラバーのテクスチャを使用。

1st/2ndの完走表示はそれぞれ「1stSTAGEクリア」「2ndSTAGEクリア」。FINAL通常完走と通し挑戦完走だけが「完全制覇」。新規ステージの練習完走は「練習クリア」です。

`tests/night-pilot.mjs` は座標・進行フラグを書き換えず、画面と同じ入力で全エリアを通過する回帰用パイロットです。UIハンドラーの起動・一時停止・通し挑戦での進出/終了もheadlessで検証。実機ブラウザでのGPU描画、音や操作感の比較、本家映像とのフレーム単位の一致は未検証です。

## v8.1 操作・接地の見直し

2nd/FINALの通常操作をタップ主体へ簡略化。着地は下降中の床面交差時のX/Z位置で判定し、岸の奥・横への飛び越しを着地としません。着地できなかった時は水面まで重力で落下して失敗。連絡足場への降下も重力で床に止めます。メタルスピンの離手速度は新しい有限の岸の判定に合わせて調整。ログ離手後の体の回転を滑らかに戻します。

## スクリューハンマーの開始タイミング調整

挑戦ボタンを押してから1秒待機後に回転開始。回転速度を従来の80%とし、1周の回転時間は6秒から7.5秒へ変更。待機中のつかまりは無効。起動から合計8.5秒で一周を終えて停止し、2周目はありません。

## 夜ステージの照明調整

2nd・FINALに白色の補助投光と環境光を追加。主照明・露出を増やし、遠景の霧を薄くしてセットの輪郭・足場・選手を見やすくしました。会場の照明器具も発光します。空は夜のままです。

## v9 接触面の統一・FINAL操作変更

- 2ndはスパイダーランとドロップを1エリア（13m）に統合し、全10エリア。ドロップ部分の壁・フレームが一緒に下がる。最後は引き続きウォールリフティング。
- `src/night/geometry.mjs` の寸法を描画・接触の両方から利用。立てる足場は有限の範囲を持ち、床面交差時の位置で着地。足場間の空間は床としない。支持面と選手の足元、ラダーのバーと両手、板と手、チェーンと手を同じ座標に揃えた。
- ログは黄色の円筒に沿った抱きつき姿勢。胴体を円筒表面の外側に配置し、身体の長軸をログと平行にして手足を回す。着地後は立位へ戻り靴底を地面へ揃える。
- メタルスピンは5mの実体のある助走路から跳び込む。空中でチェーンに実際に届いた時だけ回転開始。進入速度から角速度を計算する。

## 本体の消音設定に連動する音声・FINAL BGM（2026-11-10）

## 全4ステージのオフライン保存

初回のオンライン利用時に、Service Workerがホーム・全ステージ・ローカルJS/CSS/Three.js・FINAL動画/MP3をまとめて保存する。ホームに進捗と「オフラインで遊べます」を表示し、保存失敗時は再試行可能。保存完了前やブラウザの保存データ削除後は通信が必要。Wi-Fi・モバイル通信を切った後もステージ選択・ガチSASUKEのクエリー付き遷移・練習・BGMを同一オリジンのキャッシュから読み込める。iPhoneはSafari共有メニューからホーム画面へ追加可能。

ビルド出力を走査し、全ファイルの内容からキャッシュバージョンとプリキャッシュ一覧を生成する。更新版は全アセットを保存してから待機し、既存のゲーム中タブを強制更新しない。新workerの有効化時にこのアプリの旧キャッシュだけ削除する。動画・音声のRangeリクエストに206/416で応答し、通知や外部サーバーを必要としない。失敗時も既存キャッシュは削除しない。

生成済みworkerを実行するテストで、全アセットの保存、完全通信遮断後の全ステージ/通し挑戦/BGM読み込み、メディアのバイト範囲、保存失敗と再試行、旧キャッシュの更新を検証する。実機Safariでのオフライン起動と音声出力は未検証。


### iPhoneのBGMだけ無音になる問題への対応

効果音は鳴るがBGMだけ無音という報告に対し、Audio Session APIとMP4再生に対応する環境では、ユーザーの「挑戦する」クリック内で元動画の`play()`を直接呼び出す方式へ切り替える。音声出力のセッションはambientを指定し、動画をミュートせず1pxのまま音声を再生する。Web AudioのBGMデコード・バッファ出力はこの経路では使用せず、二重再生を避ける。動画の再生Promiseが解決してからカメラ演出を始める。失敗は捕捉し、演出内にBGM状態と再試行ボタンを表示する。API未対応環境は従来のambient Web Audio経路を維持する。Safari実機の音声出力は未確認のため、修正の有効性は実機で確認が必要。
